# Samsung Health Viz v0.0.10 — 日历热力连续取色，修复折线乱序斜线

日历热力图从「四档台阶」换成无极连续色阶：数据集中在某段里程时，20km 和 60km 不再
撞进同一档显示成同一个颜色。另外修复了一个恼人的小 bug——详情页速度/心率折线偶尔
出现一条横贯全图的斜线，根因是三星 live_data 里的点不保证按时间排序。
手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.10。

## 修复

- **折线乱序斜线**：三星 live_data 个别点 start_time 插错位置，折线按数组顺序连点就往回画；
  现在解析时按时间稳定排序，详情页渲染前也统一排序，**已缓存的旧数据集不必重新导入**即可正常显示。
  同一个乱序数组参与累计里程计算导致的里程偏差也一并修复。

## 调整

- **无极连续取色**：原先分位数 + 固定里程刻度最多表现 4 级台阶，20km 与 60km 可能同色；
  现在按当前数据集最大值归一化、色带停靠点连续插值，任意两个不同里程必得不同颜色。
- **配色观感**：天/月视图共用同一套 heatStops 色带；低档位用半透明而非浅米色，
  深色主题下空格不再被照成刺眼白块；月视图空格改用与日视图相同的底色，不再是透明黑洞。
- **统一图例**：新增共用色带组件 HeatLegendBar，替换 ECharts visualMap 与手写仿制两套实现；
  支持横向（日视图右下角渐变条）/ 纵向（月视图日历右侧），圆角、字号、对齐完全一致。
  悬停色带可批量高亮区间内的格子，悬停格子时指示器与数值标签跟随，行为对齐 ECharts。
- **统一用词**：「天视图」改为「日视图」。
- 自检增补连续取色用例（越界夹两端、退化区间、alpha 插值等），`pnpm check:calendar` 27 项。

## 升级说明

- 数据包缓存格式未变，v0.0.4 及之后解析过的数据包可直接继续使用。
- 本机 `settings.json` 里的 `calendarView`、底图、Stadia API Key、主题与语言偏好均保留。
- 折线乱序修复对旧缓存生效，无需重新导入；如对某次骑行的里程数字有疑，重新导入一次可用排序后的数据重算。
- 手机直传 App 版本号同步为 0.0.10，无功能变化。
