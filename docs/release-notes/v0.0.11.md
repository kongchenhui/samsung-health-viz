# Samsung Health Viz v0.0.11 — 自动更新改版：静默检测、红点提示、确认后下载

本版本重做了自动更新：不再在启动时弹原生对话框打断你，而是后台静默检测，发现新版本只在
设置齿轮上亮一个小红点，点进去就能看到版本号、更新说明入口和下载进度条。
另外关掉最后一个窗口就直接退出应用，macOS 上不再留一个「看不见但还占着局域网端口」的后台进程。
手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.11。

## 调整

### 自动更新
- **检测静默**：启动 8 秒后检查一次、之后每 6 小时一次；没新版本或断网只写日志，不弹窗、不打扰。
- **红点提示**：发现新版本或已下载待安装时，主窗口右上角设置齿轮与设置侧边栏「关于」出现红点；
  点击齿轮会直达「设置 → 关于」，不再只是打开设置首页。
- **下载需确认**：`autoDownload` 关闭，点「下载更新」才开始；进度条显示百分比、已下载/总量与速度，
  主进程对进度事件节流到约 4 次/秒再广播到界面。
- **状态回归界面**：原先的「发现新版本 / 更新已就绪 / 已是最新 / 检查失败」原生弹窗全部移除，
  改成设置页「关于」里的一张更新卡片（状态徽章 + 说明 + 操作按钮）；检查更新用不用得上，
  一眼就能看到，不用记上次弹窗说了什么。
- **平台差异更明确**：Windows（NSIS）与 Linux AppImage 可下载并重启安装；Linux deb 没有
  electron-updater 安装器、macOS 未签名时 Squirrel.Mac 无法校验安装包，这两个平台只引导去发布页手动下载，
  不再让用户在下载/安装阶段撞上一个看不懂的错误。
- 新增调试参数 `--update-mock=<phase>`（`idle` / `checking` / `available` / `downloading` /
  `downloaded` / `up-to-date` / `error` / `dev`），配合 `--shot` 可离线截图更新卡片的各种状态。

### 窗口生命周期
- **关掉最后一个窗口即退出**：`window-all-closed` 直接 `app.quit()`，macOS 也一样。
  本项目没有菜单栏托盘，也没有必须活到进程退出之后的任务（更新检查定时器、局域网直传接收器都随进程存活），
  留着后台只会让 Dock 图标一直亮着、还继续占着局域网端口。
- 释放时机不变：`before-quit` 关掉局域网接收器，UDP 广播与 HTTP 端口都会释放。

## 稳健性

- **检查重叠不吞结果**：后台定时检查恰好与手动检查重叠时，手动检查的「已是最新 / 检查失败」
  结果会被吞掉、界面卡在「检查中…」；现在只有手动检查才置标记，后台检查不覆写。
- **错误不覆盖已下载**：下载完成后紧邻到达的错误事件会把状态从「已下载」覆盖成「失败」，
  导致红点消失、安装按钮不可达；现在下载中/已下载状态不会被错误事件回退。

## 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `SamsungHealthViz-0.0.11-arm64.dmg` | 拖入 Applications |
| macOS | `SamsungHealthViz-0.0.11-arm64.pkg` | 安装到 /Applications |
| macOS | `SamsungHealthViz-0.0.11-arm64.zip` | 免安装版 |
| Windows x64 | `SamsungHealthViz-0.0.11-x64.exe` | NSIS 安装器 |
| Windows x64 | `SamsungHealthViz-0.0.11-x64.zip` | 免安装版 |
| Linux x64 | `SamsungHealthViz-0.0.11-x86_64.AppImage` / `*.deb` | 可执行 / 安装包 |
| Android | `SamsungHealthViz-Bridge-0.0.11.apk` | 手机直传 App（debug 签名，需允许安装未知来源） |

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）；Android 8.0+（API 26+），需与电脑处于同一局域网。

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，此前解析过的数据包可直接继续使用，无需重新导入。
- 本机 `settings.json` 里的底图、Stadia API Key、主题、语言与日历视图偏好均保留。
- macOS 上的更新仍需手动下载安装包（应用未签名，无法自动安装）；Windows 与 Linux AppImage
  可在设置页直接下载并重启安装，已下载的更新也会在正常退出应用时自动安装。
- 手机直传 App 版本号同步为 0.0.11，无功能变化。
