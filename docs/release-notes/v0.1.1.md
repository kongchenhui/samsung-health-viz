# 骑行生涯 v0.1.1 — 首个版本

把三星健康导出的数据包变成可浏览的「骑行生涯」桌面应用：总览、记录、单次详情、全部路线地图，数据全部在本地解析。

## 主要功能

### 数据包导入
- 选择 `samsunghealth_*.zip` 或解压后的目录即可解析，无需手工整理 CSV；
- 自动读取 45 个 CSV 与 3 万余个 JSON 附属文件，解析后缓存，二次打开直接加载；
- 支持拖拽 / 菜单选择，解析过程有进度与日志。

### 生涯总览
- 汇总 KPI：总里程、总时长、累计爬升、总消耗、平均速度、有轨迹次数；
- 按年份统计、个人最佳（最长距离 / 最长骑行时间 / 最快平均速度 / 最大爬升 / 最大消耗）；
- 骑行日历热力图（按月展示每日里程）；
- 按城市自动聚类，可在「全部 / 各城市」之间切换；
- **全部骑行路线绘制在一张地图上**，起点、轨迹描边、悬停摘要、点击进入单次详情。

### 骑行记录与单次详情
- 记录列表支持按年份、区域筛选；
- 单次详情：轨迹按速度着色、速度 / 心率 / 海拔 / 踏频图表、每公里分段配速、骑行环境（天气、温度、湿度、风速）。

### 地图与坐标处理
- 底图主题：高德 · 暗色（默认）、高德 · 标准、高德 · 卫星（中文标注）、Esri 卫星、OpenStreetMap、无底图（离线）；
- 轨迹深色描边 + 起点圆点，以及「底图淡化」滑杆，避免底图道路盖住轨迹；
- **坐标基准自动判定**：三星健康导出包不记录坐标系，应用会按轨迹点格式（手机 App 写入 vs 手表记录）+ 设备类型判断每条轨迹是 GCJ-02 还是 WGS-84，再按底图基准自动换算，因此手表与手机记录的骑行都能贴合地图（已用 31 条轨迹 / 1966 个采样点校验）。

### 数据说明页
- 数据包信息、表与字段清单、解析日志，方便核对原始数据。

## 使用

1. 打开应用，选择三星健康导出包（`samsunghealth_*.zip` 或解压目录）；
2. 解析完成后进入「生涯」页；
3. 之后启动会直接用本地缓存（`~/Library/Application Support/骑行生涯/`，Windows 为 `%APPDATA%\骑行生涯\`）。

## 说明与限制

- 首期仅处理**骑行**记录（`exercise_type = 11007`），步数/睡眠/心率等其他数据暂未展示；
- 部分骑行没有心率或海拔数据，对应图表会留空；
- 高德 / 卫星 / OSM 底图需要联网加载瓦片；「无底图」模式可完全离线查看轨迹；
- 数据仅在本地解析与展示，不会上传到任何服务器；
- 应用未做代码签名与公证，仅提供手动安装方式。
