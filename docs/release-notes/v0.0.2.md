# Samsung Health Viz v0.0.2 — 自动更新

在 v0.0.1 的基础上，本版本加入应用内自动更新（增量更新），并修复轨迹解析的尾段截断问题。

## 新增

### 应用内自动更新
- 基于 `electron-updater` + GitHub Release：启动 8 秒后检查一次，之后每 6 小时检查一次；菜单「帮助 → 检查更新…」可手动检查；
- **Windows（NSIS）**：自动下载并按 blockmap 做**差量更新**，下载完成后提示重启安装；
- **Linux（AppImage）**：自动下载并更新（同样支持差量）；
- **macOS**：系统要求 Squirrel.Mac 校验代码签名，当前构建未签名，因此只提示「发现新版本」并打开发布页，需手动下载安装包；
- 更新元数据（`latest*.yml` / `*.blockmap`）随 Release 资产自动上传。

### 发布流程
- 推送 `v*` 版本 tag 即自动触发三平台构建，并**自动创建并发布** GitHub Release，不再需要网页手动发布；
- 发布前会自动校验 tag 与 `package.json` 的 `version` 一致，避免版本错位；
- Release 正文自动读取 `docs/release-notes/<tag>.md`。

## 修复

- **轨迹「起点和终点没闭合」**：三星健康的 `duration` 是运动时长（不含自动暂停），而轨迹点时间戳是墙钟时间；此前按 `duration` 裁剪会把暂停之后的尾段（例如返程最后几分钟）整段截掉，导致轨迹看起来没有闭合。现在改用 `end_time - start_time` 的墙钟跨度裁剪，自动暂停后的返程不再丢失，速度/里程曲线的尾部也一并修复。

## 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `SamsungHealthViz-0.0.2-arm64.dmg` | 拖入 Applications |
| macOS | `SamsungHealthViz-0.0.2-arm64.pkg` | 安装到 /Applications |
| macOS | `SamsungHealthViz-0.0.2-arm64.zip` | 免安装版 |
| Windows x64 | `SamsungHealthViz-0.0.2-x64.exe` | NSIS 安装器 |
| Windows x64 | `SamsungHealthViz-0.0.2-x64.zip` | 免安装版 |
| Linux x64 | `SamsungHealthViz-0.0.2-x86_64.AppImage` / `*.deb` | 可执行 / 安装包 |

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）。

> 当前构建**未签名、未公证**，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 说明与限制

- macOS 自动更新需要 Developer ID 代码签名 + 公证，当前版本未签名，因此 mac 端只提示手动下载；
- 首期只做**骑行**（`exercise_type = 11007`），同一数据包里的步数、睡眠、心率等数据暂未接入；
- 高德 / 卫星 / OSM 底图需要联网加载瓦片；「无底图」模式可完全离线查看轨迹；
- 数据仅在本地解析与展示，不会上传到任何服务器。
