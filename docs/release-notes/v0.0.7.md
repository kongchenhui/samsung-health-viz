# Samsung Health Viz v0.0.7 — 窗口几何与页面滚动体验

本版本集中修复窗口与滚动相关的体验问题：窗口大小、位置与最大化状态会被记住（独立设置窗口同样生效，拖到屏幕边缘后重启也不会丢尺寸）；主窗口按页面、设置页按分栏各自记住滚动位置；同时按「用户数据不国际化」的约定，天气等导出原文不再翻译。手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.7。

## 新增

### 窗口几何记忆
- 主窗口与设置窗口分别记住大小、位置和最大化状态，重启或关窗重开后还原（使用 Electron 内置的窗口状态持久化）。
- 窗口拖到屏幕边缘、部分超出屏幕时，下次启动会夹回可见区域并**保留尺寸**；只有记录完全不在任何屏幕内（例如拔掉外接显示器）才回落到默认几何。
- 结束开发进程（`pnpm dev` 的各种结束方式）也不会丢失记忆；`--window-size` 调试运行不写入记忆。

### 页面滚动位置
- 主窗口按页面记住滚动位置：第一次进入的页面从顶部开始，返回列表页回到原来的位置（从骑行详情返回列表不再跳回顶部）。
- 设置窗口按分栏记住滚动位置，切回看过的分栏回到原位。

## 调整

- 导出数据不再国际化：天气短语等用户数据按导出原文展示；界面语言只影响界面文案与日期 / 时长等格式。
- 维护者文档补充窗口几何、滚动位置与用户数据约定；窗口记忆改用 Electron 内置能力，移除第三方窗口状态库。

## 修复

- 开发模式下窗口大小、位置、最大化状态不记忆，以及结束 dev 后调整丢失的问题。
- 切换页面时滚动条位置沿用上一页、返回列表页位置不对的问题。
- 窗口拖到屏幕边缘后重启尺寸被重置为默认的问题。

| macOS（Apple Silicon） | `SamsungHealthViz-0.0.7-arm64.dmg` | 拖入 Applications |

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）；Android 8.0+（API 26+），需与电脑处于同一局域网。

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，v0.0.4 及之后解析过的数据包可直接继续使用。
- 本机 `settings.json` 里的底图、底图淡化、Stadia API Key、主题与语言偏好会保留。
- 窗口几何改由系统侧记录；旧版本留下的 `window-state*.json` 不再使用，可以删除。
- 手机直传 App 版本号同步为 0.0.7，无功能变化。
