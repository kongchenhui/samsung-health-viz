# Samsung Health Viz v0.0.3 — 手机直传

本版本加入「手机 → 电脑」局域网直传：在手机上选中三星健康导出目录，App 自动打包 ZIP 并通过同一 Wi-Fi 上传到电脑，桌面端收到后自动解析、刷新界面，不再需要数据线或网盘中转。另修复了首次没有数据包时无法进入「数据」页的问题。

## 新增

### 手机直传（Android App + 桌面端接收器）
- **Android App**（源码 `android/`，纯 Java、零第三方依赖，minSdk 26，APK 约 40 KB）：
  - 用系统文件选择器（SAF）选三星健康导出目录，自动识别 `samsunghealth_*` 目录结构，无需存储权限；
  - 边遍历边打包 ZIP，不生成临时文件；
  - 同一 Wi-Fi 下通过 UDP 广播自动发现电脑，失败可手动填 IP / 端口；
  - 6 位数字令牌校验；
  - 上传进度、实时速度、可取消，上传期间屏幕常亮；
  - 错误提示覆盖令牌错误、文件过大、电脑端忙、网络中断等场景。
- **桌面端「数据」页**新增「手机直传（局域网）」卡片：一键开启接收，显示电脑地址与 6 位令牌；接收完成自动解析并刷新缓存；接收目录可打开 / 清除，只保留最近一份上传；首次没有数据包时也可以先从这里接收。
- 协议文档 `docs/lan-upload-protocol.md`；`pnpm check` 新增直传自检（伪造导出包 → 上传 → 真实解析，12 项）。

### 发布
- CI 新增 Android 构建：产出版本化的 debug APK（`SamsungHealthViz-Bridge-<版本>.apk`），打 tag 时随 Release 一起发布，也可在手动运行工作流后从 artifact 下载。

## 修复

- 首次使用（还没有数据包）时无法进入「数据」页，导致手机直传入口不可达；现在欢迎页、顶栏和「数据」页都能进入并开启接收。
- 「当前数据包」卡片在 ZIP 文件名不匹配 `samsunghealth_<账号>_<时间>` 时把数据包误显示为「解压文件夹」。

## 手机直传使用

1. 电脑端打开「数据包 → 手机直传（局域网）」→ 开启接收，记下页面上的电脑地址与 6 位令牌；
2. 手机安装上面的 APK（允许安装未知来源），并与电脑连接同一 Wi-Fi；
3. 手机 App 自动发现电脑（或手动填 IP / 端口）→ 输入令牌 → 选择三星健康「下载个人数据」得到的导出目录 → 打包并上传；
4. 电脑端收到后自动解析并刷新，无需其他操作。

电脑端需在防火墙放行 TCP 8737（上传）与 UDP 8738（发现）；macOS 15+ 还会询问「本地网络」权限，需允许。

## 说明与限制

- 手机直传只在可信局域网内使用（明文 HTTP + 6 位令牌防误传）；
- Android App 为 debug 签名、未上架应用商店，仅用于自用 / 侧载；
- 当前构建环境没有真机 / 模拟器，App 只验证到构建与静态检查，真机安装与联调需自测；如遇目录授权或发现失败欢迎反馈；
- 其余同前：首期只做骑行（`exercise_type = 11007`）；底图瓦片需要联网；数据只在本地解析与展示，不会上传到任何服务器（手机直传为局域网内点对点传输）。
