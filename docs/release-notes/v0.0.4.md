# Samsung Health Viz v0.0.4 — 更快的手机直传

本版本重构了「手机 → 电脑」局域网直传：改为**先在手机上并行打包，再整包上传**，支持关闭压缩，上传带长度与 SHA-256 校验；桌面端接收后可看到接收耗时与速度。Android 直传 App 同步升级到 v1.2.0。

## 新增

### 手机直传（Android App v1.2.0）
- **两阶段传输**：先把导出目录并行打包成临时 ZIP（线程数 = CPU 核心数，最多 16），再按固定长度整包上传；
- 上传失败或取消时保留临时 ZIP，点「重试上传」直接复用，不需要重新打包；
- **可选压缩**：默认开启 deflate（level 1，省流量）；局域网很快时可关闭压缩，打包更快，但 ZIP 体积接近导出目录的原始大小；选择会记住；
- 选完目录即可开始上传，不再预先扫描两万多个文件；
- 上传带 `Content-Length` 与 `SHA-256`；电脑端校验长度与校验和，不匹配直接拒绝并删除半成品。

### 桌面端
- 「数据包 → 手机直传」完成后显示：接收耗时、接收速度、解析耗时；
- 接收器支持校验 `Content-Length` 与 `X-File-SHA256`（旧版 chunked 上传仍兼容）。

## 手机直传使用

1. 电脑端打开「数据包 → 手机直传（局域网）」→ 开启接收，记下电脑地址与 6 位令牌；
2. 手机安装上面的 APK（允许安装未知来源），与电脑连接同一 Wi-Fi；
3. 手机 App 自动发现电脑（或手动填 IP / 端口）→ 输入令牌 → 选择三星健康导出目录；
4. 按需勾选「压缩 ZIP」（默认开启）→ 点「开始上传」：先打包，再自动上传；电脑端收到后自动解析并刷新。

电脑端需在防火墙放行 TCP 8737（上传）与 UDP 8738（发现）；macOS 15+ 还会询问「本地网络」权限，需允许。

## 说明与限制

- 打包后的临时 ZIP 需要至少 128 MB 空闲空间；ZIP 条目数上限 65535、单文件上限 64 MB；
- 关闭压缩时 ZIP 体积≈原始导出大小（可能几百 MB），打包更快但上传耗时完全取决于局域网速度；
- 手机端目前只验证到构建与静态检查（本机没有真机 / 模拟器），真机安装与联调需自测；如遇问题欢迎反馈；
- 其余同前：首期只做骑行（`exercise_type = 11007`）；底图瓦片需要联网；数据只在本地解析与展示，手机直传仅在局域网内点对点传输。
