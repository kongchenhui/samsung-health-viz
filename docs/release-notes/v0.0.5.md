# Samsung Health Viz v0.0.5 — 地图全屏与 Stadia 底图

本版本集中升级地图能力：新增地图全屏、接入 Stadia Maps 全系 9 款底图、把底图偏好持久化到本机配置文件，并修复了地图图层可能盖住弹窗的问题。手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.5。

## 新增

### 地图
- **全屏查看**：地图卡片右上角新增全屏按钮，铺满内容区并保留顶部标题栏；`Esc` 或再次点击退出；全屏下底图切换、底图淡化、年份/区域筛选照常可用。
- **Stadia Maps 全系 9 款底图**（桌面端使用 API Key）：
  - Alidade Smooth / Alidade Smooth Dark / Alidade Bright / Alidade Satellite；
  - Outdoors；Stamen Toner / Stamen Terrain / Stamen Watercolor；OSM Bright。
  - 按各样式要求展示版权（Stadia Maps / OpenMapTiles / OpenStreetMap，Stamen 系列另含 Stamen Design，卫星底图含 CNES / Airbus DS / PlanetObserver）。
- **底图偏好持久化**：底图主题、底图淡化、Stadia API Key 统一写入本机配置文件
  `<userData>/settings.json`（macOS：`~/Library/Application Support/Samsung Health Viz/settings.json`），下次启动自动恢复。
- **底图选项文案**：去掉「推荐」与全部括号。
- **修复**：Leaflet 内部图层 z-index 溢出，轨迹/瓦片可能画在 Key 弹窗、进度遮罩与 Toast 之上；现在统一限制在地图面板内。

### 数据页
- 新增「地图底图（Stadia Maps）」卡片：填写 / 更换 / 清除 Key，显示是否已配置，并提供获取 Key 的入口。

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）；Android 8.0+（API 26+），需与电脑处于同一局域网。

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，v0.0.4 及更早解析过的数据包可直接继续使用；
- 此前没有底图偏好持久化，升级后按默认值（高德 · 暗色 / 淡化 18）初始化，选好底图后会记住；
- Stadia 底图需要自己的 API Key：注册免费账号后在「数据」页填写，Key 只保存在本机
  `settings.json`；免费额度不含 Alidade Satellite（需 Standard 及以上套餐）；
- `tiles.stadiamaps.com` 在国内直连可能不稳定，需要代理时请确认系统代理已开启（Electron 跟随系统代理）。

## 说明与限制

- 地图瓦片需要联网；数据只在本地解析与展示；
- Stadia 免费档有每月额度，用尽后对应底图会加载失败；
- 其余同前：首期只做骑行（`exercise_type = 11007`）。
