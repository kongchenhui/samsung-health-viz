# Samsung Health Viz v0.0.9 — 骑行日历新增近一年天视图

本版本给生涯页的骑行日历加了「月视图 / 天视图」两种模式：天视图是 GitHub 贡献图样式的近一年每日热力，
一年骑得勤不勤、哪几天在骑车，一眼就能看出来。视图选择会记住，下次打开保持上次的样子。
手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.9。

## 新增

- **骑行日历天视图**：53 周 × 7 天网格覆盖近一年，每个方块代表一天，颜色越深当日里程越多；底部汇总「近一年 N 天有骑行 · 总里程」，右下角带四档图例。
- **视图切换**：日历卡片右上角「月视图 / 天视图」胶囊按钮，鼠标悬停即时显示该日日期、里程与骑行次数。
- **记住选择**：切换结果写入本机 `settings.json` 的 `calendarView` 字段，重启后保持；主窗口与设置窗口之间同步。
- 新增 `pnpm check:calendar` 自检（25 个用例：跨周对齐、闰年、未来日期占位、分位数色阶、同日多次骑行累加、锚点回退等），并并入 `pnpm check`。

## 调整

- 天视图悬停样式与月视图共用同一套配色（`emphasis` 描边、`tip*` 浮层），悬停描边由原来的近黑色改为琥珀色，两种视图观感一致。
- 天视图格子随窗口宽度自适应并保持正方形，宽屏下限制最大尺寸后居中，不会把方块拉成大色块。
- 每列从周几开始由界面语言决定（中文周一起、英文周日起），星期标签只标周一 / 周三 / 周五三行。
- 修正中文界面在单次骑行时误显示英文「1 ride」的问题（补齐 `zh` 的单数文案）。

|---|---|---|
| macOS（Apple Silicon） | `SamsungHealthViz-0.0.9-arm64.dmg` | 拖入 Applications |

| macOS | `SamsungHealthViz-0.0.9-arm64.zip` | 免安装版 |

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，v0.0.4 及之后解析过的数据包可直接继续使用。
- 本机 `settings.json` 里的底图、底图淡化、Stadia API Key、主题与语言偏好会保留。
- 老配置没有 `calendarView` 字段时默认使用月视图，行为与之前一致；切到天视图后该字段会写入配置。
- 手机直传 App 版本号同步为 0.0.9，无功能变化。
