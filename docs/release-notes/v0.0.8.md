# Samsung Health Viz v0.0.8 — 跟随系统主题时底图同步修复

本版本是一个修复版本：修正「主题切到跟随系统后，界面变成深色、地图底图却仍是浅色」的问题，并让主窗口与设置窗口之间的主题 / 底图联动更可靠，不再出现旧底图覆盖新状态、甚至被写回配置的情况。手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.8。

## 修复

- 系统为深色时，从「浅色」切到「跟随系统」后界面变深、地图底图仍停在浅色（高德标准 / 浅色 Alidade），需要重启才恢复的问题。
- 主窗口与设置窗口互相切换主题时，另一窗口广播的旧底图会覆盖刚联动好的深 / 浅底图，并可能把旧值写回 `settings.json`。
- 连点不同主题模式时，主题与底图可能回跳到前一次选择的问题（只应用最后一次切换）。

## 调整

- 主题判定改为以主进程解析出的实际明暗（`nativeTheme`）为准，不再依赖渲染层可能滞后的 `prefers-color-scheme`；运行中系统外观变化时仍即时跟随。
- 「底图跟随主题」开启时，底图若与生效主题不一致会自动对齐一次；用户手动选择过的底图、没有明暗成对版本的底图保持不动。
- 主题切换的偏好落盘放到联动底图之后，避免把切换前的旧底图广播给其它窗口。

## 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `SamsungHealthViz-0.0.8-arm64.dmg` | 拖入 Applications |
| macOS | `SamsungHealthViz-0.0.8-arm64.pkg` | 安装到 /Applications |
| macOS | `SamsungHealthViz-0.0.8-arm64.zip` | 免安装版 |
| Windows x64 | `SamsungHealthViz-0.0.8-x64.exe` | NSIS 安装器 |
| Windows x64 | `SamsungHealthViz-0.0.8-x64.zip` | 免安装版 |
| Linux x64 | `SamsungHealthViz-0.0.8-x86_64.AppImage` / `*.deb` | 可执行 / 安装包 |
| Android | `SamsungHealthViz-Bridge-0.0.8.apk` | 手机直传 App（debug 签名，需允许安装未知来源） |

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）；Android 8.0+（API 26+），需与电脑处于同一局域网。

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，v0.0.4 及之后解析过的数据包可直接继续使用。
- 本机 `settings.json` 里的底图、底图淡化、Stadia API Key、主题与语言偏好会保留。
- 旧版本可能把「跟随系统 + 浅色底图」写进配置；启动时会按当前系统明暗自动对齐底图，无需手动修改配置。
- 手机直传 App 版本号同步为 0.0.8，无功能变化。
