# Samsung Health Viz v0.0.6 — 独立设置窗口与中英双语

本版本重构了设置与外观：设置从主窗口拆成独立窗口，集中管理主题、语言、地图与数据包；新增深色 / 浅色主题和中文 / English 双语，界面文案与城市坐标改为 JSON 数据；同时修正了地图、配色与设置页交互的一批问题。手机直传 App 无功能变化，版本号随桌面端统一为 v0.0.6。

## 新增

### 设置窗口
- 设置独立成单独窗口（左侧导航 + 右侧内容）：**通用 / 地图 / 数据 / 关于**，从标题栏右上角齿轮打开；单例，重复打开只聚焦。
- 支持深链直达分栏：`#/settings?tab=general|map|data|about`；窗口内切换分栏会同步地址，欢迎页「手机直传」直接落到「数据」栏。
- 主窗口里所有进入设置页的入口统一走路由拦截，始终打开独立窗口，不会把主窗口切换成设置页。

### 外观与语言
- 主题：**深色 / 浅色 / 跟随系统**。
- 语言：**中文 / English**；界面文案、主进程菜单与弹窗都跟随切换，默认仍为中文（不猜测系统语言）。

### 数据与地图
- 数据包选择、手机直传、当前数据包信息、清除缓存全部集中到设置窗口。
- 地图路线聚类按最近的**地级行政区**命名（国内覆盖全部地级行政区与港澳台主要城市，共 348 个点位；境外按国家一个 JSON 文件维护）。
- 地图全屏、退出全屏以及窗口尺寸变化后，会自动重新测量并回到轨迹视野。

## 调整

- 主窗口顶部导航只保留「生涯 / 骑行记录」，设置入口改为右上角齿轮；设置不再占用主窗口。
- 界面文案改为 `src/locales/zh.json` / `en.json`（主进程与渲染层共用），城市坐标改为 `src/renderer/data/cities/<国家>.json`；新增语言/国家只需增加文件。
- 设置页布局参考系统设置，统一行高与分组；滚动条跟随深浅主题。
- README 精简为面向用户的内容，维护者文档移到 `docs/development.md`，并新增 `AGENTS.md`。
- 全部界面截图更新为当前版本（虚构演示数据，已脱敏）。

## 修复

- 浅色主题下轨迹、图表等数据颜色被整体压暗、对比不足的问题（结构色与数据色分开处理）。
- 数据包只有短距离骑行时，「个人最佳」可能报错的问题。
- 从生涯页下钻到单次骑行时，导航错误高亮「生涯」的问题。
- 设置页滚动条不跟随主题的问题。
- 地图全屏/窗口缩放后视野未重新适配的问题。

## 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `SamsungHealthViz-0.0.6-arm64.dmg` | 拖入 Applications |
| macOS | `SamsungHealthViz-0.0.6-arm64.pkg` | 安装到 /Applications |
| macOS | `SamsungHealthViz-0.0.6-arm64.zip` | 免安装版 |
| Windows x64 | `SamsungHealthViz-0.0.6-x64.exe` | NSIS 安装器 |

| Android | `SamsungHealthViz-Bridge-0.0.6.apk` | 手机直传 App（debug 签名，需允许安装未知来源） |

系统要求：macOS 11+（arm64）、Windows 10+（x64）、主流 Linux 发行版（x64）；Android 8.0+（API 26+），需与电脑处于同一局域网。

> 桌面端仍未签名、未公证，首次打开会被系统拦截：
> - macOS：右键 → 打开，或执行 `xattr -dr com.apple.quarantine "/Applications/Samsung Health Viz.app"`；
> - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

## 升级说明

- 数据包缓存格式未变，v0.0.4 / v0.0.5 解析过的数据包可直接继续使用。
- 本机 `settings.json` 里已有的底图、底图淡化、Stadia API Key 会保留；新增主题与语言偏好。
- 设置入口从主窗口顶部的「数据」按钮改为右上角齿轮；手机直传、数据包管理都在「设置 → 数据」。
- 语言默认中文，可在「设置 → 通用」切换；主题默认跟随系统。

## 说明与限制

- 地图瓦片需要联网；数据只在本机解析与展示，不会上传。
- Stadia 底图需要自己的 API Key，免费额度不含 Alidade Satellite（需 Standard 及以上套餐）。
- 本版本仍只处理骑行数据（`exercise_type = 11007`）。
